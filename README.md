# Music Fan Database — ER Diagrams

Draw.io diagrams (UML style) for Part A of the music fan database assignment.

- `parta1.drawio` — Question 1: one diagram with the core entities (Musician, Band, Song, Album), the BandMembership and SongContribution association classes, and Genre with its four many-to-many associations.
- `parta2i.drawio` — Question 2(a): recursive Band influences association (`0..*` on both ends).
- `parta2ii.drawio` — Question 2(b): recursive Song covers association (`0..1` original, `0..*` covers).

Open each `.drawio` file with [diagrams.net](https://app.diagrams.net/) and use File → Export as PNG/PDF for the submission.
